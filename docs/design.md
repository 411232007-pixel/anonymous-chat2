# 畫面設計規格

> 這份文件記錄第一輪畫面設計的結果,做前端時照這份實作。
> 設計稿(7 個畫板):https://claude.ai/artifact/Whw7G77tXiMAPZJH6WXDDR (私人連結,只有擁有者能開)
> 要做哪些元素與行為,以 `docs/architecture.md` 第 7 節「畫面清單」為準;這份文件只補充「長什麼樣子」。
> 設計稿是靜態畫面,不能操作,所有互動行為請看 architecture.md。

---

## 1. 設計方向

- **氣質:** 安靜簡約,像深夜的電台或圖書館。內容與對話是主角。
- **整體色調:** 偏冷的中性灰底,只有一個藍紫色輔助色(用在按鈕、線上小圓點、自己的訊息泡泡、輸入框聚焦外框)。
- **淺色與深色:** 自動跟隨系統設定(`prefers-color-scheme`),不做手動切換鈕。
- **語言:** 繁體中文。
- **裝置:** 手機與電腦都要好用,手機的可點擊元件至少 44px 高。
- **名稱與說明文字(暫定):** 聊天室名稱「夜間聊天室」,副標「匿名 · 不用登入」。這是設計時暫定的,可以改。

## 2. 色彩

所有顏色都定義成 CSS 變數,元件只引用變數,不直接寫色碼。

### 2.1 介面色

| 變數 | 用途 | 淺色 | 深色 |
|---|---|---|---|
| `--bg` | 頁面底色、輸入框底色 | `#F4F4F7` | `#121316` |
| `--panel` | 卡片、頂部以外的面板、輸入區底色 | `#FBFBFD` | `#1A1B21` |
| `--line` | 分隔線、邊框、停用的按鈕底色、載入骨架 | `#E0E1E8` | `#2B2D36` |
| `--ink` | 主要文字 | `#1C1E26` | `#E7E8EC` |
| `--mute` | 次要文字(時間、提示、系統提示行、名單標題) | `#666A78` | `#9EA1AE` |
| `--accent` | 輔助色:送出鈕、進入鈕、線上小圓點、聚焦外框 | `#4A55C8` | `#A5ACFF` |
| `--accent-ink` | 放在輔助色上的文字 | `#FFFFFF` | `#101117` |
| `--mine` | 自己的訊息泡泡底色 | `#E1E4F8` | `#25284A` |
| `--other` | 別人的訊息泡泡底色 | `#FFFFFF` | `#1C1D24` |

### 2.2 提示色

| 用途 | 淺色 | 深色 |
|---|---|---|
| 錯誤文字與錯誤輸入框邊框(`--err`) | `#B3382C` | `#F2A094` |
| 斷線提示條(底色 / 文字) | 設計稿只畫了深色:`#3A2F18` / `#F0D9A0`。淺色請用同色系的淡琥珀底配深琥珀字,文字對比至少 4.5:1。 | `#3A2F18` / `#F0D9A0` |
| 限速提示文字 | `#7A5A12` | 設計稿未畫,請用同色系的淺琥珀字 |

### 2.3 使用者顏色(每個人固定一色)

- 畫面用「代號」計算出色票的索引,同一個代號永遠得到同一個顏色(規則見 architecture.md 第 5.1 節)。顏色不存進資料庫。
- 色票共 8 色,淺色與深色各一組。淺色的頭像用深色底配白字;深色的頭像用淺色底配深色字。

| 索引 | 色名 | 淺色(底色 / 文字白) | 深色(底色 / 文字 `#101117`) |
|---|---|---|---|
| 0 | 赭紅 | `#A94F3A` | `#E39A85` |
| 1 | 琥珀 | `#8F6A12` | `#DDB45E` |
| 2 | 橄欖 | `#5E7020` | `#B4C764` |
| 3 | 綠 | `#2F7A52` | `#7FCB9E` |
| 4 | 青 | `#1F7A82` | `#6CC5CC` |
| 5 | 藍 | `#3A63AD` | `#8DB0EC` |
| 6 | 紫 | `#6E4FAE` | `#B79CEA` |
| 7 | 玫瑰 | `#A8467A` | `#E5A0C4` |

說明:
- 設計稿實際用到的是 0、3、4、5、6、7 這幾色,深色另外用了 `#E5A0C4`(玫瑰)和 `#DDB45E`(琥珀);琥珀和橄欖的淺色值是補齊色票時定的,實作時請確認白字對比至少 4.5:1,不夠就再加深。
- 藍(5)與紫(6)和輔助色藍紫比較接近。如果覺得容易混淆,實作前再調整。

- **標題與空狀態標語:** Noto Serif TC(500、700),後備 `serif`。標題字距 `.04em`。
- 字體由 Google Fonts 載入。

## 5. 版面結構

### 5.1 聊天室 · 電腦(寬度大於手機斷點)

```
┌───────────────────────────────────────┬──────────┐
│ 頂部列:夜間聊天室 · 匿名 · 不用登入  ● 線上 6 人 │          │
├───────────────────────────────────────┤  線上·6  │
│ [斷線提示條,只在斷線時出現]            │  ○ 午夜雨(你)│
├───────────────────────────────────────┤  ○ 夜貓  │
│                                       │  ○ ...   │
│  訊息區(由下往上堆疊,內容置中最寬 760px) │          │
│       [有新訊息 ↓]                     │          │
├───────────────────────────────────────┤          │
│ 輸入區:[多行輸入框]  [送出 ➤]          │          │
│ Enter 送出 · Shift+Enter 換行          │          │
└───────────────────────────────────────┴──────────┘
```

- 頂部列的「線上 6 人」只是人數,名單固定在右側。
- 名單項目:顏色頭像 + 代號;自己用粗體並加「(你)」。

### 5.2 聊天室 · 手機

```
┌──────────────────────┐
│ 夜間聊天室  ● 線上 6 人 ▾ │  頂部列(點「線上 6 人」展開名單)
├──────────────────────┤
│ [斷線提示條]           │
│  訊息區                │
│       [有新訊息 ↓]     │
├──────────────────────┤
│ [輸入框(膠囊)]  (➤)   │
└──────────────────────┘
```

- 名單展開時,是浮在訊息區上方的面板,離頂部 8px、左右各留 12px,兩欄排列。再點一次「線上 6 人」(箭頭轉向)或點面板外面收起。
- 手機沒有右側名單。
- 輸入區必須避開虛擬鍵盤,不能被遮住(architecture.md 第 7.2 節)。

### 5.3 輸入代號

- 畫面置中,內容寬度電腦 420px、手機左右各留 24px。
- 由上到下:標題 → 一句說明 → 「你的代號」標籤與字數(例 `3 / 12`)→ 輸入框 → 提示或錯誤行 → 「進入聊天室」按鈕(整條寬)。
- 說明文字:「不用註冊,取個代號就能進來。這裡是匿名的,關掉分頁就算離開。」
- 預先填入上次的代號時,輸入框呈現聚焦樣式,提示行寫「這是你上次用的代號,可以直接進入,也可以修改。」

## 6. 元件規格

### 6.1 訊息

- **別人的訊息:** 靠左。左邊頭像,右邊兩行:第一行「代號(13px 粗體)+ 時間(12px `--mute`)」,第二行泡泡(`--other` 底,1px `--line` 邊框)。
- **自己的訊息:** 靠右,沒有頭像、沒有代號。上方只有時間,下方泡泡用 `--mine` 底、無邊框。
- 內容保留換行,過長自動折行,一律以純文字顯示。
- 連續同一人的訊息,設計稿沒有做合併,每則都重複顯示頭像與代號。這一版不做合併。

### 6.2 系統提示行

- 置中、12px、`--mute`,沒有背景。例:「阿柏 進來了」「月光 離開了」。
- 與訊息一起往上捲。

### 6.3 「有新訊息 ↓」按鈕

- 浮在訊息區底部置中,離底 16px(手機 12px)。
- 膠囊形,`--panel` 底、`--line` 邊框、有陰影,文字 + 向下箭頭,高度電腦 40px、手機 44px。

### 6.4 輸入區

- 電腦:多行輸入框(高 48px)+ 送出鈕(含文字與圖示);下方一行提示 `Enter 送出 · Shift+Enter 換行`,右側保留給字數提醒(接近 500 字才出現,例「剩 23 字」)。
- 手機:輸入框(高 44px,膠囊形)+ 圓形送出鈕(只有圖示,必須有 `aria-label="送出"`);沒有下方提示行。
- 輸入區用 `--panel` 底,上方 1px `--line`。

### 6.5 按鈕狀態

| 狀態 | 樣子 |
|---|---|
| 一般 | `--accent` 底、`--accent-ink` 字 |
| 停用(斷線、限速、內容無效、連線中) | `--line` 底、`--mute` 字,游標 `not-allowed` |
| 連線中(進入鈕) | 停用樣式,文字改「連線中…」,前面加旋轉箭頭圖示 |

### 6.6 圖示

- 全部使用同一套線條圖示(描邊 2px、圓角線端),不用 emoji 當介面圖示。
- 圖示僅裝飾時加 `aria-hidden="true"`;只有圖示的按鈕要有 `aria-label`。
- 用到的圖示:送出(紙飛機)、向下箭頭、展開/收起箭頭、重新整理(連線中)、時鐘(限速)、驚嘆號圓圈(錯誤)、對話框(空狀態)。
- 例外:代號本身可以含 emoji,照原樣顯示。

## 7. 狀態與提示文字

| 情境 | 位置 | 文字 |
|---|---|---|
| 代號為空 | 輸入框下方錯誤行 | 請輸入代號。 |
| 代號超過 12 字 | 同上 | 代號最多 12 個字。 |
| 代號含不能用的字元 | 同上 | 代號含有不能使用的字元,請換一個。 |
| 代號重複 | 同上,輸入框邊框變 `--err` | 這個代號有人在用了,請換一個。 |
| 連線中斷太久被送回 | 同上 | 連線中斷太久,代號已被使用,請重新選擇。 |
| 進入中 | 進入鈕 | 連線中… |
| 載入最近訊息 | 訊息區 | 灰色骨架(頭像圓 + 兩三條泡泡)+ 文字「正在載入最近的訊息…」 |
| 空聊天室 | 訊息區置中 | 標題「還沒有人說話」,內文「你來說第一句吧。」 |
| 斷線重連中 | 頂部列下方整條提示 | 連線中斷,重新連線中…(輸入框與送出鈕同時停用,輸入區提示改為「連線恢復後即可繼續發言」) |
| 送太快 | 輸入框下方 | 送太快了,請稍等一下(4 秒),秒數倒數;送出鈕停用 |
| 送出失敗 | 輸入框下方,輸入框邊框變 `--err` | 送出失敗,請再試一次;原本的文字回到輸入框 |
| 字數接近上限 | 輸入框下方右側 | 剩 23 字 |

錯誤提示用 `role="alert"`,連線與限速提示用 `role="status"`。錯誤的輸入框加 `aria-invalid="true"` 並用 `aria-describedby` 連到錯誤行。

## 9. 設計稿還沒有、實作時要補的

- **電腦與手機的斷點:** 設計稿只有 1280px 和 390px 兩個尺寸。建議在約 760px 以下切換成手機版面,中間尺寸(平板)沿用手機版面。
- **淺色的斷線提示條:** 只畫了深色版,淺色要配一組。
- **手機的限速、送出失敗、載入、空狀態:** 只在電腦尺寸的狀態卡片中畫過,手機版沿用同樣的文字與顏色,排版跟著手機輸入區調整。
- **斷線提示時的線上小圓點:** 深色斷線稿裡小圓點是灰色(`--mute`),代表不在線;正常時是 `--accent`。
- **聚焦、懸停、按下的樣式:** 設計稿只畫了輸入框聚焦。按鈕的懸停與按下請用輔助色略深/略淺處理,並保證鍵盤操作時有清楚的聚焦外框。
- **動畫:** 設計稿沒有。建議只加輕微的:新訊息淡入、名單展開收起;並遵守 `prefers-reduced-motion`。
- **設計稿中第一則訊息的寬度(233px × 22px)** 是在編輯畫面時不小心被改到的固定尺寸,不是規格,實作時請讓泡泡隨內容自動伸縮。
- **自己的訊息在深色與淺色的對比:** `--mine` 與 `--bg` 的差距很小,實作後請實際看過,不夠明顯就加深一點。
- **字級在手機的可讀性:** 12px 的時間與提示在小螢幕上偏小,實作後請在真機確認。
